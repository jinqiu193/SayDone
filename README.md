# 言出，文成

**随口说，出色写 — 用说话代替打字，AI 实时把口语变成书面表达。**

按下快捷键开始说话，再按一次，润色后的文字自动输入到光标位置。

---

## 核心功能

### 语音输入
- **鼠标键快捷操作**：上滚 = 录音识别，下滚 = 删除，滚轮按下 = 发送
- **全局快捷键**：在任何应用中按下快捷键即可口述，文字自动插入光标位置
- **按住说话 / 免提模式**：多种录音模式自由切换

### AI 智能润色
- **实时润色**：口语自动转书面语，去口癖、纠错、分段
- **多种润色风格**：DeepSeek、通义千问、Azure OpenAI 等

### AI 问答
- **一键问答**：按住 Ctrl 键直接提问，不需要切换窗口
- **上下文理解**：在输入框中直接进行文本润色、查询、文章撰写

### 知识库
- **私有知识接入**：连接自己的知识库，让 AI 更懂你的领域
- **快速检索**：按 Ctrl 键快速检索并回复

### 中国风主题
- **多主题切换**：支持多种中国风配色主题，界面美观

### 热词管理
- **AI 生成热词**：智能生成专属热词库，提升专业术语识别准确率
- **自定义热词**：支持添加、编辑、删除热词主题

---

## 快捷键

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 录音识别 | 滚轮上滚 / Alt | 语音转文字 |
| 删除 | 滚轮下滚 | 删除上一个词 |
| 发送 | 滚轮按下 / 停止录音 | 发送内容 |
| AI 问答 | Ctrl | 在输入框中直接提问 |
| 免提模式 | Shift | 按一次开始，再按结束 |

## 技术栈

| 层 | 技术 |
|----|------|
| 桌面客户端 | Tauri v2、React、TypeScript、Tailwind CSS |
| 客户端系统集成 | Rust（全局键盘钩子、剪贴板、SQLite） |
| 语音识别 | Qwen3-ASR、字节豆包 ASR、FunASR |
| AI 润色 | DeepSeek、通义千问、Azure OpenAI |

## 开发

```bash
cd client
npm install
npm run tauri dev
npm run tauri build
```

### 前置要求

- Node.js 18+
- Rust 1.75+
- Windows 10/11
